# PWA Icons Setup Guide

## Required Icons

Your PWA needs the following icon files in the `public` folder:

1. **pwa-192x192.png** - 192x192 pixels
2. **pwa-512x512.png** - 512x512 pixels

## How to Create Icons

### Option 1: Use an Online Tool
- Visit https://www.pwabuilder.com/imageGenerator
- Upload your logo/icon
- Download the generated icons
- Place them in the `public` folder

### Option 2: Manual Creation
- Create a square image (512x512px recommended)
- Use your company logo or app icon
- Export as PNG with transparent background
- Resize to create both 192x192 and 512x512 versions
- Place both files in the `public` folder

## Current Status
⚠️ **Action Required**: You need to add these icon files to make your PWA fully functional.

Until you add the icons, the app will work but may show warnings in the browser console.
