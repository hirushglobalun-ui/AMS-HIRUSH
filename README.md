# Hirush Global EMS (Employee Management System)

A comprehensive, full-stack Employee and Lead Management System developed for Hirush Global LLP. This application provides robust tools for HR administration, employee attendance tracking, leave management, and CRM/lead management.

## 🚀 Features

- **Role-Based Access Control (RBAC):** Distinct dashboards and permissions for Admin, HR, Employees, Interns, and Visitors.
- **Attendance Tracking:** Real-time clock-in/clock-out sessions, total hours calculation, and Work From Home (WFH) logging.
- **Leave Management:** Request and approve various leave types (Casual, Sick, Earned, WFH) with integrated status tracking.
- **Employee Directory & Profiles:** Secure storage of employee details, including bank information, emergency contacts, and ID documents.
- **Lead Management (CRM):** Track leads from 'Pending' to 'Completed'/'Disposed', log activities (Calls, Meetings, Emails), and manage client relationships.
- **Internal Messaging:** Built-in communication system for company-wide or direct announcements.
- **Holiday Calendar:** Track National, Company, and Other holidays.
- **Progressive Web App (PWA):** Installable web application for native-like experience on desktop and mobile.

## 🛠️ Tech Stack

- **Frontend:** React 19, TypeScript, Vite
- **Styling:** Tailwind CSS, Lucide React (Icons)
- **Database & Backend:** Firebase (Auth, Firestore)
- **Hosting:** Vercel, Vercel Blob Storage
- **Mapping:** React Leaflet
- **Charts:** Recharts
- **Data Export/Processing:** XLSX, PapaParse, html2canvas
- **AI Integration:** Google Gemini (`@google/genai`)

## 📦 Getting Started

### Prerequisites
- Node.js (v18+)
- Firebase Project Setup

### Installation

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Set up environment variables in `.env` (Firebase config, Vercel Blob token, Gemini API key, etc.)
4. Start the development server:
   ```bash
   npm run dev
   ```
